# Código de Conduta

🇧🇷 Português · 🇺🇸 [English](CODE_OF_CONDUCT.en.md)

Inspirado no [Contributor Covenant](https://www.contributor-covenant.org/), versão 2.1.

## Nosso compromisso

Queremos que participar do AQUA RUSH seja uma experiência acolhedora para todas as pessoas, independentemente de
idade, corpo, deficiência, etnia, identidade ou expressão de gênero, nível de experiência, escolaridade, situação
socioeconômica, nacionalidade, aparência, raça, religião ou orientação sexual.

## O que esperamos

- Ser gentil, paciente e respeitoso, inclusive quando discordamos.
- Criticar ideias e código, nunca pessoas.
- Receber críticas construtivas com abertura e reconhecer os próprios erros.
- Ajudar quem está começando — todo mundo já foi iniciante.
- Pensar no que é melhor para o projeto e para a comunidade.

## O que não aceitamos

- Linguagem ou imagens sexualizadas, assédio, insultos ou ataques pessoais.
- Comentários discriminatórios de qualquer tipo.
- Publicar dados privados de outras pessoas sem permissão.
- Qualquer conduta que seria inadequada num ambiente profissional.

## Como resolvemos

O mantenedor do projeto pode remover comentários, commits, issues ou Pull Requests que desrespeitem este código e,
em casos graves ou repetidos, bloquear a participação de quem o violar.

Para relatar um problema, abra uma issue ou entre em contato com o mantenedor pelo perfil
[@viniciusfantini](https://github.com/viniciusfantini). Todo relato será tratado com sigilo e respeito.

## Abrangência

Este código vale em todos os espaços do projeto (repositório, issues, Pull Requests, discussões) e quando alguém
representa o projeto em outros lugares.
