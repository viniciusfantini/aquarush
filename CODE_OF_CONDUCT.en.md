# Code of Conduct

🇧🇷 [Português](CODE_OF_CONDUCT.md) · 🇺🇸 English

Inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

## Our pledge

We want taking part in AQUA RUSH to be a welcoming experience for everyone, regardless of age, body size,
disability, ethnicity, gender identity or expression, level of experience, education, socio-economic status,
nationality, appearance, race, religion or sexual orientation.

## What we expect

- Be kind, patient and respectful, including when we disagree.
- Criticize ideas and code, never people.
- Accept constructive criticism openly and own up to mistakes.
- Help newcomers — everyone was a beginner once.
- Focus on what is best for the project and the community.

## What we don't accept

- Sexualized language or imagery, harassment, insults or personal attacks.
- Discriminatory comments of any kind.
- Publishing other people's private information without permission.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement

The project maintainer may remove comments, commits, issues or Pull Requests that violate this code and, in serious
or repeated cases, block whoever violates it from participating.

To report a problem, open an issue or contact the maintainer through the
[@viniciusfantini](https://github.com/viniciusfantini) profile. Every report will be handled confidentially and
respectfully.

## Scope

This code applies in all project spaces (repository, issues, Pull Requests, discussions) and whenever someone
represents the project elsewhere.
